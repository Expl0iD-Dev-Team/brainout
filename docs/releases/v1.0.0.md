Первая версия BrainOut для Android с игрой по сети на своём сервере. Для узкого круга: APK раздаётся напрямую, а не через этот релиз.

**Файлы**
- `brainout-1.0.0.apk` — игра для Android 7+.
- `brainout-server-1.0.0.tar.gz` — сервер той же версии, ставится по [docs/ServerSetup.md](https://github.com/Expl0iD-Dev-Team/brainout/blob/master/docs/ServerSetup.md).
- `SHA256SUMS.txt` — контрольные суммы.

**Что работает**
- Вход по HTTPS на свой сервер, лобби, Quick Play с ботами, Free Play.
- Сенсорное управление: два плавающих джойстика, кнопки оружия, перезарядки, приседания и действия, меню, таблица игроков, чат, масштаб обзора, панель «Ещё».
- Интерфейс масштабируется под экран телефона, работает системная кнопка «Назад».
- Свёрнутая игра держит матч до 5 минут, после потери сети ждёт переподключения 45 секунд.
- Отчёт о падении предлагается отправить при следующем запуске.

**Ограничения**
- Первая загрузка после установки или обновления долгая.
- Нет покупок за реальные деньги и функций Steam (мастерская, друзья).

Как играть: [docs/Players.md](https://github.com/Expl0iD-Dev-Team/brainout/blob/master/docs/Players.md). Как выпускать обновления: [docs/Release.md](https://github.com/Expl0iD-Dev-Team/brainout/blob/master/docs/Release.md).
